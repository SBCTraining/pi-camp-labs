# Pi Camp Labs

Lab code for **Intro to Electronics & Coding with Raspberry Pi** — Weber State University.

## Getting Started

1. Clone this repository on your Raspberry Pi:

   ```bash
   cd ~
   git clone https://github.com/SBCTraining/pi-camp-labs.git
   ```

2. Navigate to a lesson and run the code:

   ```bash
   cd ~/pi-camp-labs/Lesson_01_Traffic_Light_Module
   python3 01_traffic_light_module.py
   ```
